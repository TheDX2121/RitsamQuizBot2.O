Special Person — Static Site
----------------------------

How to use:
1. Edit files (index.html, styles.css, script.js).
2. Add images to assets/images/ and update the <img> src attributes.
3. Zip the folder and upload to Netlify, or push to a Git repo and connect the repo to Netlify.
4. Netlify Forms: the contact form uses data-netlify="true". You will see form submissions on Netlify dashboard.

Deploy:
- Drag & drop ZIP onto Netlify Sites or connect repository.
